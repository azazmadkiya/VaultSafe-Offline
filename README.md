# Secure Vault

Secure Vault is a modern, 100% offline-first Android password manager and secure document vault built with **Jetpack Compose** and **Material Design 3**.

## Features

- **🔐 Encrypted Local Storage**: Credentials and notes are secured locally using AES-256-GCM encryption and Android Room database.
- **🛡️ Biometric Authentication**: Quick and secure unlock using fingerprint or face recognition via Android BiometricPrompt.
- **📄 Document & ID Vault**: Dedicated safe for Aadhaar, PAN cards, driver's licenses, and passports with multi-page camera scanning and gallery photo attachments.
- **📋 Auto-Clear Clipboard**: Automatically clears copied passwords from the system clipboard after 30 seconds for enhanced security.
- **⏱️ Auto-Lock Inactivity**: Automatically locks the vault after 1, 5, or 15 minutes of inactivity.
- **🔑 Password Generator**: Built-in secure password generator with customizable length, numbers, symbols, and uppercase letters.
- **🌐 100% Offline Privacy**: Zero external servers, zero telemetry, and zero data tracking.
